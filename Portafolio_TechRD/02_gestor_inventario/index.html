Proyecto de software y bases de datos

Gestor de inventario y ventas

Aplicación de escritorio orientada a controlar productos, existencias y ventas, con separación de responsabilidades y persistencia local.

DocumentaciónVolver al portafolio

Arquitectura

Interfaz con Tkinter/ttk, reglas de negocio en un servicio independiente y persistencia mediante SQLite.

Consistencia

Las ventas y el descuento de stock ocurren dentro de una misma transacción.

Calidad

Incluye siete pruebas del servicio y validaciones para evitar operaciones inválidas.

Capacidades demostradas

CRUD de productos, control de stock, ventas, archivado, validación de entradas, consultas parametrizadas, transacciones, manejo de importes en centavos y exportación del historial.

PythonTkinterSQLiteCRUDTestingTransactions

Decisiones técnicas

El proyecto conserva el precio y costo de cada venta para proteger el historial frente a cambios posteriores del catálogo. El uso de consultas parametrizadas reduce riesgos al trabajar con datos introducidos por el usuario.
