Objetivo

Modelado relacional, integridad de datos y consultas analíticas para un escenario de ventas. El proyecto está diseñado como evidencia práctica de formación técnica y no representa datos de una empresa real.

Qué demuestra

  • Diseño y organización de datos.
  • Consultas orientadas a preguntas de negocio.
  • Integridad, validaciones y criterios de modelado.
  • Documentación reproducible para revisión técnica.
