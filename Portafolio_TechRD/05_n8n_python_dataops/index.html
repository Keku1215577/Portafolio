Proyecto técnico

DataOps Automation

n8n + Python + FastAPI + Pandas + Docker para automatizar validación, transformación y preparación de datos.

n8nPythonFastAPIPandasDockerData Quality

Problema

Los datos de ventas pueden llegar con formatos inconsistentes, cantidades inválidas o descuentos fuera de rango.

Solución

n8n recibe y orquesta el proceso; una API Python valida, normaliza y calcula métricas de los registros.

Flujo

Webhook n8n → HTTP Request → FastAPI → Pandas → validación → métricas → filas rechazadas → respuesta

Calidad de datos

  • Fecha válida.
  • Producto no vacío.
  • Cantidad positiva e integral.
  • Precio y costo válidos.
  • Descuento entre 0 y 100.

Resultados

  • Registros recibidos.
  • Registros aceptados.
  • Registros rechazados.
  • Ingresos.
  • Utilidad y margen bruto.
